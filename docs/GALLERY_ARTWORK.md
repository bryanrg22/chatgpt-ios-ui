# Original gallery fixtures

The seven PNGs under `Demo/GalleryAssets.xcassets` were generated with the built-in imagegen tool on October 8, 2026. They are original reference-inspired substitutes, **not extracted ChatGPT artwork** and not copies of private screenshot pixels. Each image was inspected before integration. The Logo tile uses an SF Symbols fish in an original circle composition. The reusable package contains no fixed gallery catalog or artwork: hosts provide `ImageTemplate` metadata and an `imagesArtwork` view resolver.

The generated files are intended only as offline demo fixtures. They approximate the reference's subjects and broad palettes; exact composition, identity, type, texture, and colors differ. No claim of pixel matching or official OpenAI asset provenance is made. All illustrated people are fictional. No reference screenshot was supplied to the generation tool.
