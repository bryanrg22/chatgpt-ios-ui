# Settings and About

The October 7 capture of About (`chatgpt-version`) shows a grouped card with Terms of use, Privacy policy, and an app/version row. This page reproduces that structure with native glass Back, adaptive grouped colors, system typography, and the existing knot vector. The source About capture is light; the dark page uses the system dark palette inferred from the captured dark settings root. Exact About dark pixels have not been captured. The root App settings order is General, Notifications, then Voice.

`ChatState.settings` owns `SettingsAccountPresentation` and `SettingsAboutPresentation`. Both default to empty metadata. Existing `ChatState.displayName`, `username`, and `email` remain forwarding aliases. The demo explicitly supplies its fictional Alex profile and Pro label. About displays the captured app version as reference metadata, not the executable's own build number. The executable version remains defined in `project.yml`.

The host supplies legal URLs and receives `SettingsAction.openLink`; reusable views do not launch a browser. Missing URLs disable the corresponding row and emit nothing. The demo uses `example.com` links and shows the requested URL locally. `openSettings(_:)` routes About and the already supported General, Personalization, Memory, and Plugins pages while emitting a typed destination action; existing generic navigation events remain for compatibility.

Observation and bound native controls follow Apple's [model-data guidance](https://developer.apple.com/documentation/swiftui/managing-model-data-in-your-app/). The metadata objects have no persistence, network requests, or account mutations. Other deep Settings and Customize destinations still await captures. Existing preference bindings and Personality Save/back behavior were not changed in this pass.

## Captured native pickers

The captured Start screen menu contains Chat and Codex, not Work. Changing it only stores the local preference, matching this package's existing behavior; it does not launch a backend or navigate immediately. The captured model menu shows GPT-6, 5.6 Sol, and 5.5 beneath its explanatory header. `SettingsPreferenceOptions` separates these labels from the original package IDs `GPT-6`, `GPT-5.6 Sol`, and `GPT-5.5`, preserving `selectModel` callback values. Unknown host-supplied model labels pass through unchanged.

Appearance, Accent color, Start screen, and Model rows show their captured up/down disclosure indicator. Accent includes its selected swatch and a distinct color for every native picker option. The swatch values approximate the saved light menu: sampled central pixels were converted from the capture's embedded color profile to sRGB. They are not claimed to be source design tokens, and existing global accent behavior is unchanged. Swatches use original 12pt circles drawn with Apple's [image renderer](https://developer.apple.com/documentation/uikit/uigraphicsimagerenderer), preserving their size and color inside a native Menu/Picker. Simulator inspection showed SwiftUI omits a single Section header and turns standalone Text into a large disabled row. The model row therefore uses a public UIKit `UIButton`/`UIMenu` bridge with its native title and checked actions, following Apple's [control-menu pattern](https://developer.apple.com/documentation/uikit/adding-context-menus-in-your-app). No manually drawn popup is used.
