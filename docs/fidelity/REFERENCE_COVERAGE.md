# Reference and interaction coverage

Reference app: **ChatGPT for iOS 1.2026.267 (36747771815)**, confirmed in its About screen during the October 7, 2026 session. Reference phone viewport: approximately 393 × 852 points. Private screenshots remain outside this distributable project. Simulator QA uses iPhone 17 Pro, iOS 27, with a different logical viewport; comparisons account for that difference.

This is an independently implemented UI skeleton, not extracted application source and not a complete or pixel-certified replica. Account names, chats, search results, and scheduled tasks are fictional.

## Implemented reference surfaces

- Chat home: glass Chat/Work switch, sidebar, temporary-chat control, optional voice announcement, two-row composer. Typing hides the announcement. Its original textured orb is approximated with an original procedural cloud field.
- Conversation: compose/ellipsis header, trailing blue user bubble, unbubbled assistant text, pending/streaming/finished states, compact composer when unfocused. Light mode uses a pale blue bubble with blue text; dark mode uses measured RGB 4/5/95 with white text for the observed Blue accent.
- Sidebar: navigation hierarchy, pinned/recent groups, new-chat button, settings, searchable local sample chats.
- Attachment popup: Camera, Photos, Files, Plugins, Think harder, large icon backplates, selected blue/check state. Native SwiftUI Menu was tested first and visibly differed in row size, order, and icon treatment. This popup uses custom content with native Liquid Glass material; its controls are not a screenshot overlay.
- User-message long press: Copy, Edit, Select text, Share prompt. Edit opens a dedicated screen with a prefilled composer; cancelling preserves the previous unsent draft.
- Assistant controls: Copy, thumbs up, thumbs down, Share, More. More offers Branch in new chat, Read Aloud, Retry, Use Pro mode, Search the web. A separate assistant long-press menu is not presented: two reference long presses showed no menu, which is recorded as an observation rather than a universal claim.
- Feedback sheet: issue picker, optional details capped at 2,000 characters, counter, close and Send. Selecting thumbs down applies the rating before the sheet; closing the report retains it. The disclosure truthfully describes this offline skeleton rather than claiming it sends data to OpenAI.
- Voice: captured first-entry Choose your voice screen, Breeze descriptor, nine indicator dots, black idle conversation with 193pt orb, compact composer/mic/X controls, settings card and captured language-menu entries. The old invented Voice preview layout is removed. Transcript/keyboard, classic sharing controls, media menus, model-switch prompt, and full-screen live camera are also implemented from subsequent JPG/video references. Orb texture uses original layered value noise and optional cosmetic drift; it remains an approximation.
- Read Aloud: top glass player, elapsed time, speed, ±15-second controls, replay/pause state, close. The demo simulates presentation only and produces no audio.
- Settings, General, Customize, Personality: observed rows, native appearance/accent menus with colored swatches, Chat/Codex start choices, captured model labels/header, local toggles, sliders, and custom instructions. Unobserved detail destinations identify their integration boundary. About reproduces the captured grouped legal-link and app/version rows using host-fed metadata and typed link intents. See `docs/features/SETTINGS.md`; the demo injects reference version metadata separately from its own executable version.
- Embedded camera: measured approximately 369 × 492 pt lower panel at 393 × 852 pt reference, compact/options-expanded controls, off/auto/on flash, flip, scan instruction and completion control. A synthetic injected preview replaces private camera pixels. Pressed shutter color follows the captured endpoint; capture/recording semantics and transition timing remain host-owned/unmeasured. The compact blue options hint is host-controlled; underlying card fragments/background layering are approximate.
- Memory summary: observed gray reading surface, title/update subtitle, menu, and bottom About panel. Fictional prose replaces private memories; refresh/delete mutate only the host-owned sample state. The delete confirmation and external Learn more destination were not captured.
- Plugins: observed catalog, Gmail detail, settings, and permission choices. Account and catalog data are fictional; selections and permission reset are local state. Try in chat inserts a draft mention. SF Symbols approximate brand icons.
- Work: blank/suggestion home, model/effort composer control, Configure model list. Suggestions are fictional; no connectors are activated.
- Temporary chat: selected temporary icon, hidden Chat/Work switch, explanation, Personalized/Unpersonalized selection sheet, disabled empty send control.
- Search and Scheduled: supplied local fixtures and interactive front-end forms. Search categories/results and scheduled tabs, task form, notification/repeat/time controls are local presentation data held by ChatState across navigation. No system task is scheduled and no notification is requested. Search filters/result detail and task icon/interval/end-date sheets are functional but unreferenced.

## Remaining limits

- Font identity and every custom icon are not verified. Most icons are SF Symbols; the temporary-chat and thinking-gauge outlines are original vector approximations. No proprietary font is bundled. The widget knot logo reuses the parent repository asset; its upstream license is not established here. See `THIRD_PARTY_NOTICES.md` for replacement and provenance requirements.
- Orb texture/motion, precise animation timing, every menu pixel, actual audio waveform, real transcription, and read-aloud audio remain unverified or deliberately host-supplied.
- Voice now uses captured chooser, idle, settings, transcript, sharing, and live-camera surfaces. Its cloud texture is still an original layered-noise approximation. Recorded large-orb diameters were about 165–218pt with a sampled startup overshoot near 225pt; compact diameters were about 69–91pt. These are observations from one recording, not design caps or an audio-to-diameter mapping. The default resting sizes (193/178/80pt) are presentation endpoints; hosts can supply finite diameters. A valid explicit host diameter bypasses the recorded automatic collapse so geometry has one owner; an early TimelineView timestamp retains the starting endpoint. The 400pt defensive host-input bound is not a measured app limit. The specific 0.5-second large-to-compact collapse uses linear interpolation through seven measured diameter/center samples, including its undershoot. The helper is unit-tested; full rendered frame-by-frame parity and the proprietary moving cloud texture remain open. Other transitions are not claimed exact.
- Codex and Your dot now have separate caller-owned state and captured destination layouts. Space now has captured browsing, filters, and image-viewer surfaces with host-owned outcomes. Explore now expands into the captured sidebar destinations, with Sites and project-draft screens implemented. Loaded directories, several account details, and additional workspace states still require reference work. Images browsing and host-fed Work task/question presentation are now included, with artwork/outcome limits documented separately. This is not whole-app completion.
- Real camera/photo/file access, sign-in, backend APIs, payments, notification scheduling, and device automation remain host responsibilities. Account-login animation remains excluded; captured feature onboarding is within scope, with additional workspace surfaces still in progress.
- iPad, Dynamic Type extremes, right-to-left locales, and all accessibility settings are not yet visually validated.

The package and its tests establish working presentation state. Passing tests does not by itself establish visual fidelity: simulator screenshots must also be inspected. During this session, screenshot review caught an oversized empty composer and a centered attachment popover that interaction-only tests had missed; these were corrected and targeted size checks added.
